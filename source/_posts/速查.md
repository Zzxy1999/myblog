# netstat

## 选项说明

- `-a`: 显示所有连接和监听端口
- `-t`: 显示 TCP 连接
- `-u`: 显示 UDP 连接
- `-l`: 仅显示监听中的端口
- `-p`: 显示进程 ID 和程序名
- `-n`: 以数字形式显示地址和端口（不解析主机名）
- `-r`: 显示路由表
- `-i`: 显示网络接口统计信息
- `-s`: 显示各协议的统计信息
- `-c`: 持续输出，每秒刷新一次

## 实用命令

### 查看所有监听端口
```bash
netstat -tulpn | grep LISTEN
```

### 查看指定端口占用
```bash
netstat -tulpn | grep :4000
```

### 查看所有 TCP 连接状态
```bash
netstat -ant
```

### 统计连接状态数量
```bash
netstat -ant | awk '{print $6}' | sort | uniq -c | sort -rn
```

### 查看路由表
```bash
netstat -rn
```

### 持续监控网络连接
```bash
netstat -c
```

# tcpdump

## 选项说明

- `-i`: 指定网络接口（如 eth0, any）
- `-n`: 不解析主机名和端口名
- `-nn`: 不解析主机名和协议名
- `-c`: 捕获指定数量的数据包后停止
- `-w`: 将数据包写入文件
- `-r`: 从文件读取数据包
- `-v/-vv/-vvv`: 详细输出（越多 v 越详细）
- `-A`: 以 ASCII 格式显示数据包内容
- `-X`: 以十六进制和 ASCII 格式显示
- `-s`: 捕获数据包的长度（0 表示完整包）
- `-D`: 列出所有可用的网络接口

## 过滤表达式

### 协议过滤
- `tcp`: 仅捕获 TCP 数据包
- `udp`: 仅捕获 UDP 数据包
- `icmp`: 仅捕获 ICMP 数据包

### 主机过滤
- `host <IP>`: 指定主机
- `src host <IP>`: 源主机
- `dst host <IP>`: 目标主机

### 端口过滤
- `port <端口>`: 指定端口
- `src port <端口>`: 源端口
- `dst port <端口>`: 目标端口
- `portrange <起始-结束>`: 端口范围

### 逻辑运算符
- `and` 或 `&&`: 与
- `or` 或 `||`: 或
- `not` 或 `!`: 非

## 实用命令

### 捕获指定接口的所有流量
```bash
tcpdump -i eth0
```

### 捕获指定主机的流量
```bash
tcpdump host 192.168.1.100
```

### 捕获指定端口的流量
```bash
tcpdump port 80
```

### 捕获 HTTP 流量（带详细内容）
```bash
tcpdump -i any -A -s 0 'tcp port 80'
```

### 捕获 HTTPS 流量
```bash
tcpdump -i any port 443
```

### 捕获两个主机之间的流量
```bash
tcpdump host 192.168.1.100 and host 192.168.1.200
```

### 捕获指定源 IP 和端口
```bash
tcpdump src host 192.168.1.100 and src port 8080
```

### 排除指定端口（如 SSH）
```bash
tcpdump port not 22
```

### 保存数据包到文件
```bash
tcpdump -i eth0 -w capture.pcap
```

### 从文件读取并分析
```bash
tcpdump -r capture.pcap
```

### 捕获前 100 个数据包
```bash
tcpdump -c 100 -i eth0
```

### 捕获 DNS 查询
```bash
tcpdump -i any port 53
```

### 捕获 ping 包
```bash
tcpdump icmp
```

### 查看完整数据包内容（十六进制+ASCII）
```bash
tcpdump -i any -X -c 10
```
