# netstat

## 选项说明

- `-a`: 显示所有连接和监听端口
- `-t`: 显示 TCP 连接
- `-u`: 显示 UDP 连接
- `-l`: 仅显示监听中的端口
- `-p`: 显示进程 ID 和程序名
- `-n`: 以数字形式显示地址和端口（不解析主机名）
- `-r`: 显示路由表
- `-i`: 显示网络接口统计信息
- `-s`: 显示各协议的统计信息
- `-c`: 持续输出，每秒刷新一次

## 实用命令

### 查看所有监听端口
```bash
netstat -tulpn | grep LISTEN
```

### 查看指定端口占用
```bash
netstat -tulpn | grep :4000
```

### 查看所有 TCP 连接状态
```bash
netstat -ant
```

### 统计连接状态数量
```bash
netstat -ant | awk '{print $6}' | sort | uniq -c | sort -rn
```

### 查看路由表
```bash
netstat -rn
```

### 持续监控网络连接
```bash
netstat -c
```

# tcpdump

## 选项说明

- `-i`: 指定网络接口（如 eth0, any）
- `-n`: 不解析主机名和端口名
- `-nn`: 不解析主机名和协议名
- `-c`: 捕获指定数量的数据包后停止
- `-w`: 将数据包写入文件
- `-r`: 从文件读取数据包
- `-v/-vv/-vvv`: 详细输出（越多 v 越详细）
- `-A`: 以 ASCII 格式显示数据包内容
- `-X`: 以十六进制和 ASCII 格式显示
- `-s`: 捕获数据包的长度（0 表示完整包）
- `-D`: 列出所有可用的网络接口

## 过滤表达式

### 协议过滤
- `tcp`: 仅捕获 TCP 数据包
- `udp`: 仅捕获 UDP 数据包
- `icmp`: 仅捕获 ICMP 数据包

### 主机过滤
- `host <IP>`: 指定主机
- `src host <IP>`: 源主机
- `dst host <IP>`: 目标主机

### 端口过滤
- `port <端口>`: 指定端口
- `src port <端口>`: 源端口
- `dst port <端口>`: 目标端口
- `portrange <起始-结束>`: 端口范围

### 逻辑运算符
- `and` 或 `&&`: 与
- `or` 或 `||`: 或
- `not` 或 `!`: 非

## 实用命令

### 捕获指定接口的所有流量
```bash
tcpdump -i eth0
```

### 捕获指定主机的流量
```bash
tcpdump host 192.168.1.100
```

### 捕获指定端口的流量
```bash
tcpdump port 80
```

### 捕获 HTTP 流量（带详细内容）
```bash
tcpdump -i any -A -s 0 'tcp port 80'
```

### 保存数据包到文件
```bash
tcpdump -i any -w capture.pcap
```

### 查看完整数据包内容（十六进制+ASCII）
```bash
tcpdump -i any -X -c 10
```

# curl

## 选项说明

- `-X <METHOD>`: 指定 HTTP 方法（GET、POST、PUT、DELETE 等）
- `-H <header>`: 添加自定义请求头
- `-d <data>`: 发送 POST 数据
- `-o <file>`: 保存响应到文件
- `-O`: 使用 URL 中的文件名保存
- `-I`: 仅显示响应头（HEAD 请求）
- `-v`: 详细输出（包括请求和响应头）
- `-k`: 忽略 SSL 证书验证
## 实用命令

### GET 请求
```bash
curl https://api.github.com
```

### 保存响应到文件
```bash
curl -o output.json https://api.github.com
curl -O https://example.com/file.zip
```

### 查看响应头
```bash
curl -I https://google.com
```

### POST 请求（JSON 数据）
```bash
curl -X POST https://api.example.com/users \
  -H "Content-Type: application/json" \
  -d '{"name":"John","age":30}'
```

### POST 请求（表单数据）
```bash
curl -X POST https://example.com/login \
  -d "username=admin&password=123456"
```

### 上传文件
```bash
curl -X POST https://example.com/upload \
  -F "file=@/path/to/file.txt"
```


# ping

## 选项说明

- `-c <次数>`: 发送指定次数的 ICMP 包后停止
- `-i <秒数>`: 设置发送间隔（默认 1 秒）
- `-s <字节>`: 设置数据包大小（默认 56 字节）
- `-t <TTL>`: 设置 TTL（Time To Live）
- `-W <秒数>`: 设置超时时间
- `-q`: 安静模式，仅显示统计信息

## 实用命令

### 基本连通性测试
```bash
ping google.com
```

### 发送指定次数的包
```bash
ping -c 5 google.com
```

### 快速 ping（0.2 秒间隔）
```bash
ping -c 10 -i 0.2 google.com
```

# telnet

## 选项说明

- `<host> <port>`: 连接到指定主机和端口

## 实用命令

### 测试端口是否开放
```bash
telnet google.com 80
```

### 测试 SMTP 服务器
```bash
telnet smtp.gmail.com 587
```

### 测试 SSH 端口
```bash
telnet 192.168.1.1 22
```
